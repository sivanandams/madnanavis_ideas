MetrcMatch

AI reconciles a cannabis license holder's point-of-sale, cultivation, and manufacturing records against their state seed-to-sale system every night, catching the tag mismatches and unlogged waste that trigger compliance audits before the state does.

Target Customer

Licensed cannabis cultivators, processors, and dispensaries in seed-to-sale-mandated states (Michigan, Missouri, Massachusetts, Colorado, Ohio, Maryland, and other METRC states, plus BioTrackTHC states like Florida and Louisiana) doing roughly $2M–$30M in revenue — especially multi-location operators and anyone who has already drawn a compliance violation, since a second one escalates fast.

Pain Point

State cannabis regulators require every plant and product unit to be RFID-tagged, tracked, and reported in near real time through a state track-and-trace system; a licensee's POS and cultivation records must match that state ledger exactly, down to the package tag. Discrepancies — missing tags, quantity deltas, waste not logged within the state's deadline, transfer manifests never confirmed on the receiving end — are exactly what a state audit is designed to find, and they carry real teeth: administrative complaints, fines from roughly $1,000 to $100,000 depending on the state and severity, and, on repeat or serious findings, license suspension or non-renewal. Reconciliation today is a compliance manager copying two systems into a spreadsheet, usually monthly at best, so most operators only discover a mismatch when an inspector already has.

MVP Workflow

  1. Operator connects their state track-and-trace API (a vendor API key issued by the state) and their POS/inventory system (Dutchie, Flowhub, or Treez) through existing integrations.
  2. Nightly pull of package, plant, and transfer records from the state system, matched against POS sales and inventory-adjustment records for the same period.
  3. Reconciliation engine matches records by package tag ID and flags quantity deltas beyond a configurable tolerance, unlogged waste, stale or expired packages, and transfer manifests missing a receiving confirmation.
  4. An anomaly-scoring layer — not a generic chatbot — ranks each discrepancy by audit risk using the operator's state-specific rule set (e.g., Massachusetts requires destroyed waste logged within 3 days), separating same-day-fix issues from lower-risk noise.
  5. A dashboard plus daily email/SMS digest lists open discrepancies and days remaining to correct each one, with a one-click "correction packet" (CSV/PDF proof of what was fixed and when) ready to hand an inspector.
  6. A monthly "mock audit" report simulates what a state inspector would flag, so operators clean up issues on their own schedule instead of the state's.

Data & Integrations Needed

METRC vendor API (per state) BioTrackTHC API (FL, LA) POS integrations: Dutchie, Flowhub, Treez, Cova State-by-state variance-threshold & deadline rule sets Discrepancy anomaly-scoring model Email/SMS alerting

Pricing Model

$399–$1,499/month priced per licensed facility (single dispensary vs. multi-site operator), since the license — not the seat — is the audit unit. A one-time $995 "mock audit + cleanup" onboarding fee pays for itself by surfacing existing discrepancies before the subscription even starts.

First Version Scope

Launch with one state (Michigan or Missouri — high plant counts, active enforcement) and one POS integration (Dutchie), covering package and plant reconciliation plus waste-logging deadline alerts only; leave multi-state support and manufacturing/production-batch matching for v1.1. Support a manual CSV upload path for operators without a live POS integration yet. Go to market through cannabis compliance consultants and state cannabis trade associations who already do this reconciliation by hand for clients and would refer or white-label it.

What Makes It Non-Obvious

Existing seed-to-sale platforms treat the state system as somewhere you report to, not a source of truth you audit against — nobody is building the shadow ledger whose entire job is catching drift between the state's official record and the operator's own systems before an inspector does. The category also comes with a built-in enforcement clock a small team can automate around: every state publishes its own exact correction windows and variance thresholds in its regulations, which makes the product's value legible and defensible without needing open-ended AI conversation — it behaves more like a compiler diffing two ledgers than a chatbot, and the "prove you fixed it" packet is what actually gets sold, not the alert itself.
