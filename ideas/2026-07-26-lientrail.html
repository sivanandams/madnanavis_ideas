LienTrail

State-compliant lien-sale workflow and audit-trail software for independent self-storage operators — so a delinquent-unit auction never turns into a wrongful-lien lawsuit.

Target Customer

Owners and on-site managers of independent and small-chain self-storage facilities (1–20 locations) who are not on an enterprise REIT compliance program — the roughly 25,000+ mom-and-pop and regional operators who make up the majority of U.S. self-storage square footage but run on SiteLink/StorEDGE for rent collection and spreadsheets or paper for everything else.

Pain Point

Every state has its own self-storage lien-sale statute governing exactly how an operator may auction a delinquent tenant's unit: minimum days delinquent before a notice can issue, certified-mail requirements, precise waiting periods (often 14–90 days and state-specific), what the notice must say verbatim, how and where the auction must be advertised, minimum time between advertisement and sale, and post-sale surplus-fund handling. Miss any one step — wrong notice period, insufficient mail proof, defective ad — and the sale is legally a "conversion," exposing the operator to tenant lawsuits for actual damages, statutory penalties, and attorney's fees that can exceed the value of everything in the unit combined. Operators currently track this by memory, a generic template downloaded from a state storage association, and a paper file — with no systematic way to prove, months later in court, that every deadline was actually met.

MVP Workflow

  1. Manager imports a delinquent-tenant list (CSV export from SiteLink/StorEDGE, or manual entry) with tenant name, unit, move-in date, facility state, and balance owed.
  2. System matches the facility's state to its lien-law ruleset and calculates every required deadline for that tenant: earliest lien-notice date, certified-mail cutoff, minimum waiting period, earliest legal auction date.
  3. System auto-generates the state-specific lien notice letter with correct statutory language and citations, ready to print or send via a certified-mail API.
  4. Each unit moves through a visible pipeline (delinquent → noticed → mail confirmed → sale-eligible → advertised → auctioned) with the manager checking off proof at each stage (mail receipt scan, ad screenshot/tear sheet).
  5. Once the waiting period clears, system generates auction-advertisement copy meeting the state's minimum publication requirements and a printable auction announcement.
  6. Every document, timestamp, and uploaded proof is compiled into a single locked case file per unit — the "defense packet" the operator hands to their attorney if a former tenant ever disputes the sale.

Data & Integrations Needed

Maintained 50-state self-storage lien law ruleset CSV import from SiteLink / StorEDGE / Storable Certified mail API (e.g. Lob) for notice delivery + proof tracking Document/PDF generation with state-specific legal templates Immutable timestamped audit log per case Optional listing push to StorageTreasures / storagestuff.bid

Pricing Model

Per-facility subscription ($59–99/facility/month) for operators with steady delinquency volume, or a pay-per-case fee (~$25–40 per lien case) for smaller single-facility owners where auctions are infrequent — case-based pricing removes the "why am I paying monthly for something I use twice a year" objection that kills adoption in this segment.

First Version Scope

Ship rulesets for the 10 states with the highest self-storage facility density (TX, FL, CA, GA, NC, OH, IL, PA, TN, VA). Manual CSV/spreadsheet import only — no live PMS integration. Deliver notice-letter generation, deadline tracking, and the exportable audit-trail case file; defer certified-mail API automation and auction-marketplace listing push to v2. Go to market through state self-storage association newsletters and SiteLink/StorEDGE user communities, where this exact liability is a recurring topic.

What Makes It Non-Obvious

Every well-funded self-storage software dollar has gone into rental, payments, and access-control (SiteLink, StorEDGE, Nokē, Storable) — none of it targets the one workflow in the industry with genuine tail-risk litigation exposure. The underlying logic is entirely deterministic (statutory deadlines and required notice language per state), which means the product's core defensibility is a well-maintained legal ruleset and an audit trail an attorney will trust, not a chatbot interface. It also travels: the same deadline-and-defense-packet engine applies almost unchanged to mobile-home-park lien sales, boat/RV storage liens, and contractor's/mechanic's liens — adjacent verticals with the identical "miss one date, get sued" shape.
